# XrmToolBox Tools

Formula81 tools for [XrmToolBox](https://www.xrmtoolbox.com), built to make working with Dynamics 365 / Power Platform **Dataverse** quicker and clearer.

📘 **Full documentation lives in the [Wiki](../../wiki).**

| Tool | What it does | Docs |
| --- | --- | --- |
| 👓 **Audit Goggles** | Explore the audit history of up to 100 records at once | [Audit Goggles Wiki](../../wiki/Audit-Goggles) |
| 🔎 **Meta Scanner** | Browse and search Dataverse metadata the friendly way | [Meta Scanner Wiki](../../wiki/Meta-Scanner) |

## 👓 Audit Goggles

**Audit Goggles** gives you a clear picture of what changed, when, and by whom.

- Select up to 100 records, from the table list or straight from a **FetchXML Builder** query
- Filter, sort and pick columns to cut the audit history down to what matters
- Color coded records for quick visual identification

→ Read more: [Adding Audit Records](../../wiki/Audit-Goggles-Adding-Audit-Records) · [Loading Entity Audits](../../wiki/Audit-Goggles-Loading-Entity-Audits)

## 🔎 Meta Scanner

**Meta Scanner** helps you find any table, column, choice or relationship fast, without wading through every property at once.

- Scan the names, descriptions and choice values of every table and column in one go
- See the key facts of a table first, with friendly column types and every other property one tab away
- Favorites, one-click copy of names, maker portal links and CSV export

→ Read more: [Browsing Tables](../../wiki/Meta-Scanner-Browsing-Tables) · [Scanning Metadata](../../wiki/Meta-Scanner-Scanning-Metadata)

## Installation

1. Open **XrmToolBox**.
2. Go to **Tools → Plugins** and search for **Audit Goggles** or **Meta Scanner**.
3. Install the tool and connect to an environment.
